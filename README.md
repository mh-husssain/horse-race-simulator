# HorseRaceSimulator
This program represents the coursework project for the OOP module of Computer Science at Queen Mary. The project is to create a game which visualises the racing of horses against eachother, side by side and lane by lane. The folder is divided into two sections as part 1 represents the game in terminal, where as part 2 does this via a GUI.
To navigate through the files:
Part1: Horse, Race, Test java files. You can also find my report.
Part2: Horse, Race, RaceGUI, NewOutputStream, Statistics, Test java files.

## Usage Requirements
To run the files with in, you will require to have atleast version 16 of the JDK, to run and compile Java. You will not need anything else. The code was also developed using the Visual Studio code IDE, so if you find any problems try running it in VS Code instead.

## Part 1 Instructions
### Files
- Horse.java
- Race.java
- Test.java
- Report.pdf

To test the classes made in part 1, try switching the test methods provided in the Test class. The test class has the methods testHorse() and startRace. Hence to test the racing simulation in terminal: download the part1 folder, open the folder and run Test.startRace(). 

Alternatively, the startRace() method is preset to be called in the main method for you, as Test.main(null).

## Part 2 Instructions
### Files
- Horse.java
- Race.java
- RaceGUI.java
- NewOutputStream.java
- Statistics.java
- Test.java

To run part 2, please download and open the folder into your workspace. Then please navigate into the Test class. Similarly, you can try running the startRaceGUI() method or use it as it is already preset in the main method.
Hence running Test.main() should be sufficient.
